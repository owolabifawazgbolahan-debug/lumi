LUMI JEWELS

Files:
- index.html
- style.css
- scripts.js

HOW TO USE
1. Open index.html with VS Code Live Server or any local web server.
2. Replace the WhatsApp number at the top of scripts.js:
   const whatsappNumber = "2348012345678";
3. The 24 collections and 72 sample products are generated in scripts.js.
4. When real product photos are ready, replace the .product-media placeholder in productCard() with your image markup, or extend the product objects with image paths.
5. The cart uses localStorage and the WhatsApp checkout automatically builds a message containing item names, quantities, prices, subtotals and total.
